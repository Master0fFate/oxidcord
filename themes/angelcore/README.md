# Angelcore

A hard-edged black instrument: void ground, square corners, thin rules and mono type. It follows the Angel Core 2026 rules from the angelcore design skill.

- Two inks. Everything is a neutral between void (`#050505`) and light (`#ffffff`). There is no hue anywhere, so the accent, links, mentions and unread pill are light greys and whites.
- Status is read by shape and brightness, not color: online is white, idle is a crescent in light grey, do not disturb is a bar in mid grey, offline is dark.
- `roundness` is 0 and every `radius_*` is 0, so avatars, server icons, badges, buttons, menus and dialogs are square.
- One hairline (`divider`, `#292929`) separates regions. Surfaces differ by a few percent of black, not by cards.
- Cascadia Mono (Consolas, then Menlo) for the whole interface, with a denser type scale (11 to 22) and shorter rows.

Install it from Settings, Themes, catalog section, or copy `theme.json` into your themes directory. No font files are needed; it uses fonts the system already has.
