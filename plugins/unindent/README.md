# Unindent

Removes the indentation all lines of a fenced code block share. It works on the messages you send (the composer shows its usual indicator that a plugin changed the message) and on the code blocks of messages you read.

Tabs are turned into four spaces first, blank lines do not count when the shared indentation is measured, and inline code is left alone.

Permissions: `message-send`, `message-render`.

Port of the Vencord plugin unindent.
