# Force Owner Crown

Adds a crown badge with the tooltip `Server owner` next to the name of the owner of the server, in messages, the member list and the profile popout, even in large servers.

Limits: the badge is added by the plugin, it is not Discord's own crown icon, so it can sit next to other badges. Direct messages and group chats have no owner badge. The owner of a server is remembered until you restart or reconnect, so a transfer of the server shows after that.

Permissions: `user-display`, `context-directory`.

Port of the Vencord plugin forceOwnerCrown.
