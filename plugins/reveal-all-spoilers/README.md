# Reveal All Spoilers

Ctrl+click on a spoiler reveals every spoiler of that message. Ctrl+Shift+click reveals the spoilers of the messages you can see in the open channel (the newest 40 that have spoilers out of the last 100).

Revealed messages stay revealed until the plugin restarts.

Limits: Vencord also accepts the Command key on macOS, this port only listens for Ctrl. A Ctrl+click on a spoiler is taken by the plugin, so it no longer reveals just that one spoiler by itself. The channel wide reveal only covers messages the client holds in memory.

Permissions: `ui-input`, `message-intercept`, `context-timeline`.

Port of the Vencord plugin revealAllSpoilers.
