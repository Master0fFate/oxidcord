# Sticker Paste

Adds a sticker button to the composer toolbar. It opens a grid with the stickers of the current server and the standard sticker packs, at most 60. Picking one attaches it to your draft, and it is sent with your next message instead of on its own.

Limitations: partial. The client's own sticker picker still sends a sticker the moment you pick it, plugins cannot change that, so use the button of this plugin to paste. The grid shows still and animated stickers, Lottie stickers are left out because they have no image.

Permissions: `ui-mount`, `context-expressions`, `composer`.

Port of the Vencord plugin stickerPaste.
