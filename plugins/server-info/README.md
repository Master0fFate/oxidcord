# Server Info

Adds Server info to the menu of a server. It opens a window with the icon, banner, name and description, and these fields: owner, creation date, members, online members (when the client knows the number), boosts with the level, channels, vanity link and the list of features.

Limits: no settings. The Friends, Blocked users and Ignored users tabs of Vencord are dropped, as are the join date, preferred locale, verification level and role count, which plugins cannot read. The online count shows only when the client has it.

Permissions: `ui-mount`, `context-directory`.

Port of the Vencord plugin serverInfo.
