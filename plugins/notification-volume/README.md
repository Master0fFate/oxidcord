# Notification Volume

Sets a separate volume for the notification sound of the client, from 0 to 100.

Settings:
- `notificationVolume`: volume of the notification sound in percent. Default 100.

Limitations: the volume applies to the notification chime, the only sound the client plays on its own. The client reverts to full volume when the plugin is turned off.

Permissions: `actions-settings`, `storage`.

Port of the Vencord plugin notificationVolume.
